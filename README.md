# Traffic Sign Recognition

## Описание проекта

Проект выполнен в рамках производственной (проектно-технологической) практики на кафедре «Программная инженерия» МТУСИ (Вариант 5 — Классификация дорожных знаков).

**Цель работы:** разработка комплексной системы детекции и распознавания дорожных знаков на основе методов глубокого обучения, экспериментальное сравнение нескольких современных архитектур нейронных сетей и создание интерактивного демонстрационного приложения.

В ходе работы был реализован полный цикл разработки CV-системы: подготовка и аугментация данных, обучение и валидация 5 различных классификационных архитектур, интеграция детектора YOLO для локализации объектов и сборка финального локального веб-приложения.

---

## Используемый датасет

**German Traffic Sign Recognition Benchmark (GTSRB)**
- Количество изображений: **73 139**
- Количество классов: **43**
- Источник: [Kaggle — Traffic Signs Classification](https://www.kaggle.com/datasets/flo2607/traffic-signs-classification)

---

## Использованные архитектуры

Для решения задачи классификации были обучены и протестированы следующие глубокие архитектуры:
- **ResNet50**
- **DenseNet121**
- **MobileNetV3-Large**
- **EfficientNet-B0**
- **Vision Transformer (ViT-B16)**

Для предварительной локализации (детекции и кропа) дорожных знаков на комплексных дорожных сценах использовалась предобученная модель **YOLO** (`yolo_traffic_fixed.pt`).

---

## Результаты экспериментов

Сравнительный анализ обученных моделей на тестовой выборке:

| Модель | Accuracy |
| :--- | :---: |
| **ResNet50** | **99.43 %** |
| ViT-B16 | 99.22 % |
| MobileNetV3 | 98.85 % |
| EfficientNet-B0 | 98.47 % |
| DenseNet121 | 97.99 % |

*Архитектура **ResNet50** показала наилучшую точность и была интегрирована в финальное приложение в качестве основного классификатора.*
